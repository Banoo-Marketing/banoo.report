# Focus Rules

These rules are non-negotiable. Atlas enforces them regardless of context.

## Hard Limits

| Rule | Limit | Status |
|------|-------|--------|
| Active initiatives | Max 3 | Enforced at API + UI |
| Daily tasks | Max 3 | Enforced at API + UI |
| Revenue streams tracked | Max 5 | Soft limit |
| Active growth engines per week | Max 2 | Planning constraint |

## Focus Load Status

| Count | Status | Action |
|-------|--------|--------|
| 0–2 initiatives | 🟢 GREEN | Normal operation |
| 3 initiatives | 🟡 YELLOW | At capacity — no new initiatives |
| 4+ initiatives | 🔴 RED | Overload — kill lowest ROI immediately |

## What Counts as an Initiative

An initiative is any sustained effort requiring weekly attention:
- A new client acquisition campaign
- A product/service build
- A partnership development
- A content/distribution effort
- A job search campaign

NOT an initiative:
- A single email or task
- A one-time deliverable
- Ongoing client maintenance

## Focus Enforcement Protocol

When focus is RED:
1. List all active initiatives by ROI score (low to high)
2. Kill the bottom 1–2 immediately (require reason)
3. Do not start anything new until status returns to GREEN
4. Run REALIGN command to reset

## Common Focus Violations

- Starting a new initiative "just to explore it"
- Running 2 job searches + 2 agency pitches + 1 product build simultaneously
- Treating every interesting idea as an active initiative
- Keeping "zombie" initiatives alive past their kill condition

## Atlas Intervention Triggers

Atlas must intervene when:
- More than 3 active initiatives detected
- New initiative requested while at >2 active
- No kills in past 7 days despite RED status
- Over-planning without execution movement
