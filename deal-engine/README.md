# Emod's Deal Engine

Autonomous outbound engine. Runs every 3 hours. Finds PI law firm prospects.
Creates 2 Gmail drafts. You review and send.

## What it does each run

1. **Gmail scan** — finds dormant contacts (PI lawyers, 60–180 days no contact) → PATH A warm re-engage
2. **SEMrush** — finds PI firms actively advertising in Ontario/GTA → PATH B cold authority pitch
3. **Claude** — writes personalized 3-4 line email per prospect
4. **Gmail API** — creates draft, ready to review and send

## Setup (one time, ~10 minutes)

### 1. Install dependencies

```bash
cd deal-engine
npm install
```

### 2. Copy env file

```bash
cp .env.example .env
```

Fill in your credentials (see `.env.example` for all required keys).

### 3. Get your Google refresh token

```bash
npm run setup
```

- Opens a browser auth flow
- Sign in as **emod@banoo.marketing** or **emadvafa@gmail.com**
- Copy the `GOOGLE_REFRESH_TOKEN` printed in terminal into `.env`

### 4. Run a test

```bash
npm test
```

Runs one cycle immediately. Check Gmail Drafts for results.
Check `logs/` for what was found and drafted.

### 5. Start the engine (every 3 hours)

```bash
npm start
```

Keep this running in a terminal or deploy to a server / PM2.

## Environment variables

| Variable | Required | Description |
|---|---|---|
| `GOOGLE_CLIENT_ID` | ✓ | OAuth2 client ID (Desktop app type preferred) |
| `GOOGLE_CLIENT_SECRET` | ✓ | OAuth2 client secret |
| `GOOGLE_REFRESH_TOKEN` | ✓ | Generated by `npm run setup` |
| `SENDER_EMAIL` | ✓ | Email address to send from |
| `ANTHROPIC_API_KEY` | ✓ | Claude API key for email generation |
| `SEMRUSH_API_KEY` | ✓ | SEMrush for finding PI firm advertisers |
| `GOOGLE_API_KEY` | optional | For future Google Search enrichment |

## Switching to emod@banoo.marketing

If the Google OAuth is set up under emadvafa@gmail.com but you want to send
from emod@banoo.marketing (Google Workspace):

1. Change `SENDER_EMAIL=emod@banoo.marketing` in `.env`
2. Re-run `npm run setup` and sign in with the Workspace account
3. Update `GOOGLE_REFRESH_TOKEN` with the new token

## Logs

Each run writes to `logs/run_YYYY-MM-DDTHH-MM-SS.txt`.
Contains: prospects found, email subjects, draft IDs, errors.

## Cron schedule

`0 */3 * * *` — runs at 12am, 3am, 6am, 9am, 12pm, 3pm, 6pm, 9pm.

To change frequency, edit `src/index.js` line with `cron.schedule`.

## Architecture

```
src/
  index.js       — cron scheduler + entry point
  engine.js      — orchestration: find prospects → write emails → create drafts
  gmail.js       — Gmail REST API: scan inbox + create drafts
  semrush.js     — SEMrush API: find PI firms spending on Google Ads
  emailWriter.js — Anthropic Claude: personalized email generation
  logger.js      — file-based run logging
```
